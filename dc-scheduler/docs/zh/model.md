# 模型说明（推导与实现细节）

> 这份文档解释"为什么这样建"，代码在 `src/optimizer.py`。
> 读者只需要会加减乘除 + 知道"线性规划 = 在一堆直线围成的区域里找最低点"。

---

## 1. 核心量只有三个

| 量 | 含义 | 单位 | 为什么是核心 |
|---|---|---|---|
| $x_t$ | 第 $t$ 个 15 分钟内跑多少**可延迟算力** | MW（IT 侧） | 唯一能自由搬的东西 |
| $g_t$ | 从电网买多少电 | MW | 所有成本和绝大部分碳排的来源 |
| $E_t$ | 储能电量 | MWh | 唯一能"把电存到以后用"的东西 |

其他都是它们的函数：机房用电 $=\mathrm{PUE}\cdot(L^{rig}_t+x_t)$，光伏 $s_t$ 由天气决定，电池充放 $c_t,d_t$ 只改变 $E_t$。

---

## 2. 完整模型

### 2.1 目标函数

$$
J=\sum_{t=1}^{T}\Big[\underbrace{p_t g_t\Delta t}_{\text{电费}}+\underbrace{\lambda e_t g_t\Delta t}_{\text{碳成本}}\Big]+d_{deg}\sum_t (c_t+d_t)\Delta t+\varepsilon\sum_t u_t\Delta t
$$

| 符号 | 含义 | 单位 | 量纲检查 |
|---|---|---|---|
| $p_t$ | 分时电价 | 元/MWh | $p\,g\,\Delta t$ = 元/MWh × MW × h = **元** ✓ |
| $e_t$ | 电网碳强度 | kgCO₂/MWh | $e\,g\,\Delta t$ = **kg** ✓ |
| $\lambda$ | 碳价 | 元/kg | $\lambda e g\Delta t$ = **元** ✓ |
| $d_{deg}$ | 电池吞吐折旧 | 元/MWh | **元** ✓ |
| $u_t$ | 功率变化量（辅助变量） | MW | **元** ✓ |
| $\Delta t$ | 15 分钟 = 0.25 h | h | |

> 最容易错的就是单位：$\Delta t$ 必须以**小时**计，功率以 MW 计，两者相乘才是 MWh。
> 我们在开发中真的踩过这个坑——电价按"元/kWh"直接代进去，算出来一天电费 93 元，立刻发现不对。

### 2.2 约束

**(1) 功率平衡**（每个时段一条）
$$g_t+s_t+d_t=c_t+\mathrm{PUE}\cdot(L^{rig}_t+x_t)$$
左边是三条供给（电网、光伏、放电），右边是两条需求（机房、充电）。单位都是 MW。

**(2) 可延迟算力总量**
$$\sum_{t=1}^{T}x_t\Delta t=W=100\ \text{MWh}$$
这是"活必须干完"。

**(3) 截止期**
$$x_t=0\quad\text{对所有 } t\ge t_{dl}$$
实现上不写约束，直接把上界设成 0 —— 更省求解器力气。

**(4) 储能动态（含效率）**
$$E_t=E_{t-1}+\eta\,c_t\Delta t-\frac{d_t\Delta t}{\eta},\qquad 0\le E_t\le E_{max}$$

$\eta=0.95$ 是单向效率，往返 90%。注意充电乘 $\eta$（存进去打折），放电除 $\eta$（取出来要更多）。
这一项是后面"储能不减排"结论的根源。

**(5) 循环约束**
$$E_T=E_0$$
不允许"今天充满、明天不管"，否则模型会把电池当免费电池用。

**(6) 容量与功率上限**
$$0\le g_t\le G_{max}=15\ \text{MW},\quad 0\le s_t\le \bar s_t,\quad 0\le c_t,d_t\le B_p=5\ \text{MW}$$

**(7) 功率平滑**（把 |·| 线性化）

想让算力别忽上忽下，本来要写 $\min\sum|x_t-x_{t-1}|$，这不是线性的。标准技巧：

$$u_t\ge x_t-x_{t-1},\qquad u_t\ge x_{t-1}-x_t,\qquad u_t\ge 0$$

因为目标里 $u_t$ 的系数是正数，最优解会把它压到 $|x_t-x_{t-1}|$。**约束松弛但目标最小化 ⇒ 等价**。电池充电也做了同样处理（否则 LP 的多解性会让充电变成一堆脉冲，图很难看也不现实）。

### 2.3 规模

| 项 | 数量 |
|---|---|
| 变量 | $8\times96=768$（含平滑辅助变量） |
| 等式约束 | $2T+2=194$ |
| 不等式约束 | $4(T-1)=380$ |
| 求解时间 | 约 20 ms（HiGHS） |

## 3. 为什么是 LP，不是别的

| 备选 | 为什么不选 |
|---|---|
| 混合整数规划（MILP） | 任务不可拆分、启停成本本质是整数问题。但 96 时段 × 多个作业会爆，且单日收益提升 <2% |
| 动态规划 | 状态是 (t, 剩余电量, SOC)，SOC 连续 ⇒ 必须离散，精度和维度都吃亏 |
| 强化学习 | 需要大量仿真环境，且**不可解释**——评委问"为什么这么排"答不上来 |
| 贪心/规则 | 我们实现了（`verify.greedy`），比最优差 25%，只配当上界 |
| **线性规划** ✅ | 可证最优、可解释、20 ms、加约束只需加一行 |

**LP 的一个额外好处**：对偶变量就是"影子价格"。
$g_t$ 约束的对偶值 = 那一度电的边际成本；$W$ 约束的对偶值 = **多给 1 MWh 算力额度值多少钱**。
这直接回答了"该不该扩容、该不该买储能"。

## 4. 帕累托前沿怎么画

加权和法：让 $\lambda$ 从 0 扫到很大，每个 $\lambda$ 解一次 LP，得到一族 $(\text{费用},\text{碳排})$。

**为什么加权和在这里是精确的**：LP 的可行域是凸多面体，目标线性，所以所有有效解都在凸包的"下边界"上，加权和能取到全部。不需要 ε-约束法（虽然代码里也留了 `carbon_cap` 参数）。

**折中点怎么定**：把费用和碳排各自归一化到 [0,1]，取到原点距离最小的点
$$\text{knee}=\arg\min_{k}\ \Big[\big(\tfrac{J_k-J_{min}}{J_{max}-J_{min}}\big)^2+\big(\tfrac{E_k-E_{min}}{E_{max}-E_{min}}\big)^2\Big]$$

本算例落在 $\lambda=1.535$ 元/kg（1,535 元/tCO₂）。

## 5. 验证设计（Phase 2.5）

| 检查 | 做什么 | 为什么能证明 |
|---|---|---|
| 可行性复核 | 从解向量重新算功率平衡、SOC 递推、总量、截止期 | 排除"解出来了但物理上不成立" |
| 双算法交叉 | 对偶单纯形 vs 内点法 | 排除求解器 bug |
| 小规模穷举 | 4 时段 × 21 档 = 194,481 组全枚举 | 直接对照，最硬的证据 |
| 独立贪心 | 另写一套规则 | 排除"目标函数写错导致虚假最优" |

穷举那个测试特别值得说：它把连续问题**离散化后暴力搜**，
如果 LP 给出的值比穷举还低很多，就说明约束漏了；如果一致，说明模型是紧的。
实测两者**完全相等**（21,649.62 元），这是最有说服力的一个数字。

## 6. 踩过的坑（给后来者）

1. **单位**：元/kWh 直接当元/MWh 用，电费小了 1000 倍。
2. **奇异性**：电池 $E_0=10$ 但 $E_{max}=0$ 时不可行——敏感性扫描时忘了同步改初始电量。
3. **多解性**：LP 最优解不唯一，同一费用下有几十种排班，充电功率呈脉冲状。加平滑项后稳定。
4. **退化测试**：穷举测试最初选的时段光伏过剩，购电恒为 0，费用恒为 0，"通过"了但什么都没验证。换到 17–20 时才有意义。
5. **字型**：matplotlib 默认字体没有中文和下标 ₂，出图会一堆小方块。
