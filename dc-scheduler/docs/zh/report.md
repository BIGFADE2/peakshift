# 峰谷算力 PeakShift：AI 数据中心的算力-电力协同调度

> HackSHSID 2026 · Track 2
> 一句话：**把能等的训练任务挪到"便宜又有光"的时段，用储能把中午的光搬到晚高峰。**
> 一个线性规划模型，`scipy` 求解，11 项独立验算全过，代码可一键复现。

---

## 0. 先看懂这道题在问什么

赛题只给了三句话，但每一句都在说"两边不同步"：

| 赛题原话 | 翻译成建模语言 |
|---|---|
| 绿电便宜但不稳定，不够时要从电网买 | 供给有两个来源：**零成本、零碳、但不稳定**的光伏，和**有价格、有碳强度**的电网 |
| 算力需求也在变，任务还有不同紧急程度 | 负荷有两类：**不能等**的（在线推理）和**能等**的（训练、离线批处理） |
| 最便宜、最干净的时刻，不是需求最高的时刻 | 这就是**错配**，也是本题唯一的杠杆：**时间维度上的搬运** |

所以整道题其实是一道"**搬运题**"：把什么搬、能搬多少、搬到哪、代价是什么。

没有数据，所以第一步不是建模，而是**给现实拍一张照片**。

## 1. 第一步：把数据中心拆开（这是最容易被跳过的一步）

AI 数据中心的算力不是一团。按"能不能等"拆四类：

| 任务类型 | 典型例子 | 功率特征 | 能否挪动 | 我们怎么处理 |
|---|---|---|---|---|
| 在线推理 | 聊天、搜索、推荐 | 2–4.5 MW，跟用户走，晚高峰最高 | ❌ 不能，延迟 SLA 是硬约束 | 当成**给定曲线**，不决策 |
| 训练 | 大模型预训练 | 单任务能吃满 8 MW，跑几天 | ✅ 能，靠 checkpoint 暂停/恢复 | **决策变量** |
| 离线推理 / 批处理 | 数据清洗、embedding、评测 | 中等、可拆小块 | ✅ 能 | **决策变量**（并入上面） |
| 存储/网络等 | — | 占比小 | — | 并入刚性负荷 |

> 为什么训练能挪？因为训练通常跑几天，暂停点靠 checkpoint，代价约 1–2% 的重复计算。
> 这就是我们把调度粒度定在 **15 分钟**、并且给功率变化加了平滑惩罚的原因——不允许作业"跳来跳去"。

## 2. 模型：一个能讲清楚的线性规划

### 决策什么（每 15 分钟一组，一天 96 组）

| 符号 | 含义 | 单位 |
|---|---|---|
| $x_t$ | 可延迟算力功率 | MW |
| $g_t$ | 从电网买电 | MW |
| $c_t,\ d_t$ | 电池充/放功率 | MW |
| $s_t$ | 实际消纳的光伏 | MW |
| $E_t$ | 时段末储能电量 | MWh |

### 约束（每条都对应一句人话）

$$
\begin{aligned}
&\text{功率平衡} && g_t+s_t+d_t=c_t+\mathrm{PUE}\cdot(L^{rig}_t+x_t) && \text{买电+光电+放电=用电+充电}\\
&\text{算力守恒} && \sum_t x_t\Delta t=W && \text{100 MWh 必须干完}\\
&\text{截止期}   && x_t=0,\ t\ge t_{dl} && \text{20:00 前必须交活}\\
&\text{储能动态} && E_t=E_{t-1}+\eta c_t\Delta t-d_t\Delta t/\eta && \text{充放有损耗}\\
&\text{储能容量} && 0\le E_t\le E_{max},\ 0\le c_t,d_t\le B_p && \text{别充爆、别超功率}\\
&\text{变压器}   && g_t\le G_{max} && \text{15 MW 上限}\\
&\text{光伏}     && 0\le s_t\le \bar s_t && \text{不能凭空发电}
\end{aligned}
$$

### 目标

$$
\min\ \underbrace{\sum_t p_t g_t\Delta t}_{\text{电费}}+\underbrace{\lambda\sum_t e_t g_t\Delta t}_{\text{碳成本}}+\underbrace{d_{deg}\sum_t(c_t+d_t)\Delta t}_{\text{电池折旧}}+\underbrace{\varepsilon\sum_t u_t\Delta t}_{\text{功率平滑}}
$$

$\lambda$ 是碳价（元/kg）。$\lambda=0$ 时只图钱，$\lambda$ 很大时只图碳，中间就是帕累托前沿。

### 为什么用线性规划

1. **能证最优**：求解器直接给出对偶界，不用"跑得挺好"来搪塞。
2. **能解释**：每个约束都有物理含义，电价的对偶变量就是"这一度电的影子价格"。
3. **能扩展**：加需量电费、加碳排放上限，都是加一行约束的事，不用换模型。
4. **够快**：768 个变量 0.02 秒解完，可以嵌进实时系统。

## 3. 结果

![图2 优化后的 24 小时](../results/figures/fig2_schedule.png)

排班长这样（图 2）：

- **深夜 00–08**：把 8 MW 可延迟算力全塞进谷段，同时用 1.3 MW 匀速把电池充满（不是猛冲，避免抬高峰值）。
- **上午 08–11**：算力减半，让光伏接上。
- **中午 11–14**：**电网购电降到 0**——最脏的时段，机房完全靠光伏运行。
- **17–18**：算力清零，把晚高峰整段让出来。
- **18–22**：储能放电顶住刚性负荷，电网几乎不出力。

### 和不调度比

| 方案 | 日总费用 | 日碳排 | 峰值购电 |
|---|---|---|---|
| 不调度（算力均匀摊平，电池闲置） | 92,822 元 | 99,092 kg | 10.1 MW |
| 只移峰 | 72,394 元（**−22.0%**） | 100,956 kg（+1.9%） | 11.8 MW |
| 只加储能 | 84,313 元（−9.2%） | 100,131 kg（+1.0%） | 13.9 MW |
| **完整方案** | **64,518 元（−30.5%）** | 101,890 kg（**+2.8%**） | 13.1 MW |
| 低碳方案（$\lambda$ 拉满） | 103,940 元（+12.0%） | 85,173 kg（−14.0%） | 15.0 MW |

![图3 三组指标的相对变化](../results/figures/fig3_compare.png)

**30.5% 的电费、一度电 435 元（原来 654 元）——但碳排反而升了 2.8%。**
这不是 bug，是本题最有意思的地方。

## 4. 逐条回答赛题的五个问题

### Q1. "好"怎么定义？用什么衡量？

我们不用单一数字，用四个：

1. **钱**：日总费用 = 电费 + 电池折旧（元/天）
2. **碳**：日碳排放（kgCO₂/天）
3. **电网友好度**：峰值购电（MW）——变压器容量和需量电费都由它决定
4. **服务**：可延迟算力是否在截止期前全部交付（本模型里是硬约束，恒满足）

再补一个可比的效率指标：**每买 1 MWh 电要花多少钱、排多少碳**（度电成本 / 度电碳强度）。

### Q2. 比"不调度"好在哪？好多少？

- **钱：−30.5%**，一天省 28,304 元，按 365 天算约 **1,033 万元/年**。
- **碳：+2.8%**，也就是**变差了**。
- 峰值：10.1 → 13.1 MW，**变差了**。

我们不打算掩饰后两项。诚实地说：**只优化电价的调度，是"省钱但增排"的。**
但帕累托前沿给出了修正方案：从最低费用点往折中点走，**多花 6,870 元（+10.6%），少排 6.0 tCO₂（−5.9%）**，这条曲线上的每一步都同时优于"不调度"。

![图4 费用-碳排帕累托前沿](../results/figures/fig4_pareto.png)

### Q3. 凭什么相信它接近最优？

四道独立的证据，全部可以复跑（`python src/verify.py`）：

| 证据 | 结果 |
|---|---|
| 对偶界 = 原目标值 | HiGHS 报告 `optimal`，对偶间隙 0 |
| **换算法**再解一遍（对偶单纯形 vs 内点法） | 目标值差 **3.4×10⁻¹⁶** |
| **小规模穷举**：4 时段 × 21 档功率 = 194,481 种排班 | LP = 穷举最优 = **21,649.62 元**，一分不差 |
| **独立贪心**（按电价排序填谷） | 80,736 元 ≥ LP 64,518 元 |
| 可行性复核 8 项（功率平衡、SOC、截止期、上下限…） | 残差 ≤ 10⁻¹⁴ |

> 第 3 条最关键：我们把问题缩小到 4 个时段，把功率离散成 0.2 MW 一档，**把所有可行方案全部枚举一遍**，
> 结果和 LP 完全一致。这说明 LP 没有"偷"出一个现实中做不到的更优解。

### Q4. 条件变了还成立吗？什么时候会失效？

![图5 四组敏感性](../results/figures/fig5_sensitivity.png)

**（a）光伏预测误差 ±15%，蒙特卡洛 200 次**（图 6）：省钱比例均值 29.2%，5% 分位 28.2%，**最差 27.6%，200 次全为正**。
完全预知的理想上界是 30.7%——也就是说预测误差只吃掉 1.5 个百分点，因为电池会吸收偏差。

![图6 鲁棒性](../results/figures/fig6_robustness.png)

**（b）会失效的边界**（重要）：

| 条件 | 会发生什么 |
|---|---|
| 截止期收到 12:00 | **直接无解**：100 MWh 装不进 96 MWh 的窗口 |
| 截止期收到 14:00 | 仍可行，但省钱从 30.5% 掉到 29.6%，减碳恶化到 −3.5% |
| 换成"中午谷段"电网（山东式鸭子曲线） | 更赚：省钱 **39.4%**，减碳 **+2.4%** |
| 换成"夜间风电充足"电网 | 减碳 **+14.2%**，方案从"增排"变"减排" |
| 夜间碳强度 > 680 kg/MWh | 减碳变负（本算例 740，正好落在负区） |

### Q5. 假设合理吗？错了会怎样？

| 假设 | 强度 | 若假设不成立 |
|---|---|---|
| 训练任务可暂停（有 checkpoint），粒度 15 min | 强 | 若完全不可中断，可延迟电量降为 0，方案退化为"只加储能"，省钱从 30.5% 掉到 9.2% |
| 电价按分时电价事先公布 | 强 | 若改成实时电价，需在线滚动优化，方法不变 |
| 光伏"用不完就弃"，不能上网卖电 | 中 | 若可上网，弃光变成收入，排班会更激进 |
| 电网碳强度白天低、夜里高 | **弱** | **这是最脆弱的假设**。换成夜间风电充足的场景 C，储能的结论直接反转（见 Q4） |
| 储能成本线性、无寿命衰减 | 中 | 会略微高估套利收益，方向不变 |

## 5. 三个反直觉的发现

### ① 最便宜 ≠ 最干净，而且差距是量级上的

峰谷比 3.2× 的时候，电价信号会把算力全部推向**碳强度最高**的谷段。
纯省钱方案省了 30.5%，代价是碳排 +2.8%。**这是"绿色调度"最容易踩的坑。**

### ② 储能只会省钱，不会减排

直觉是"储能能把中午的光搬到晚上"。但在这个算例里：

- 中午的光伏**本来就被算力吃干净了**，没有余量可存；
- 电池实际充的是**深夜的煤电**（740 kg/MWh），放给晚高峰（760 kg/MWh）；
- 加上 90% 往返效率，每放 1 MWh 要充 1.11 MWh。

算一下就知道：放 1 MWh 少排 760 kg，但充它多排 822 kg —— **净增 62 kg**。
所以储能装得越大，减碳越差（图 5a：0 MWh 时 −1.8%，40 MWh 时 −4.4%）。

**结论：储能的环保价值，取决于它充的是什么电，而不是它有多大。**

### ③ 碳价基本没用，加光伏才有用

碳价从 0 涨到 1000 元/t，排班**一动不动**（图 5c）。
要涨到 **2000 元/t**（当前全国碳市场价的 20 倍以上）才开始改变。

原因是：前沿上的边际减排成本高达 **2,358 元/tCO₂**，远高于碳价。
而把光伏从 8 MW 加到 16 MW，立刻变成**双赢**：省钱 50.8%，减碳 25.7%。

**结论：想让 AI 数据中心变绿，装光伏比买碳配额有效得多。**

## 6. 局限与下一步

1. **单日模型**：真实需量电费按**月峰值**计费，一天定不了月峰值。我们用"日峰值代理"做了实验（`results/tables/demand_charge.csv`）：需量电费 600 元/MW/天时，最优方案会主动把峰值从 13.1 压到 12.8 MW，代价是总费用 +12%。完整的做法需要 30 天滚动优化。
2. **确定性**：只做了光伏不确定性的蒙特卡洛，没有做两阶段随机规划或鲁棒优化。
3. **任务粒度**：把所有可延迟任务当成一池能量，没有区分"作业不可拆分"的整数约束。真实场景需要 MILP。
4. **没考虑算力迁移/跨地域**：如果允许把任务送到别的电价区，收益会更大（"负载迁移"是业界主流做法）。
